# HW1 – AI in Business: Healthcare Navigation

This repository contains a written reflection on how generative AI can help address challenges in healthcare navigation, with a focus on international students facing language barriers and unfamiliar medical systems. The draft was created with AI assistance and then edited into a final version.

## Git Steps Used

1. Initialized a local repository and made an initial commit to set up the project.
2. Created `assistant_draft.md` using Claude Code and committed it to the feature branch `claude/create-assistant-draft-cwMaE`.
3. Edited the draft and saved the revised version as `final_version.md`, then committed the changes.
4. Created this `README.md` to document the repository and committed it as the final update.
5. Pushed all commits to GitHub using `git push -u origin <branch>`.
